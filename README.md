# A4カメラ校正PoC 1.5
公開先: https://a4-cylinder-camera-pose.daisukedaisuke389137.chatgpt.site
A4の印刷模様からカメラの3D位置・向きを求める試作です。既定は壁などに固定した平らな紙の既知寸法からIPPE/PnPで推定します。認識した紙の枚数に固定上限は設けず、同じIDを印刷した別の紙を分離します。初期画面の各紙の姿勢から、基準紙に対する位置・回転を登録します。各カメラが同じ基準紙を選ぶことが共通原点の条件です。基準紙を見失っても登録済みの別の紙から姿勢を求められます。人体点の三角測量は使いません。筒の実形状復元も選べますが、実動画で継続位置推定は未達です。画像・動画・Webカメラを入力できます。人体推定は含みません。
## リアルタイムの位置と角度
通常の再生が本来の動作です。最新の表示フレームを読み、処理中のフレームは溜めません。requestVideoFrameCallbackの表示時刻を使い、同じ表示フレームの重複処理を防ぎます。250msの固定待機を廃止しました。初回は全画面を探索し、以後は登録した紙の予測領域だけを取得・認識します。紙の登録は「紙を探し直す」でやり直せます。初期探索と追加登録には、基準紙と登録する紙を映します。初期化時に上から順に紙番号を付けるため、異なる向きの映像では青枠が同じ実物を示すよう映像をクリックして選択します。
3D位置とヨー・ピッチ・ロール、回転行列を表示・保存します。角度の基準は基準紙の右・上・表側です。ロールは視線軸回りで、鉛直を向く特異姿勢では未定義です。書き出しのanglesDegreesとangleConventionに規約を記録します。レンズ値が仮の画角の場合、絶対座標・角度の精度は未校正です。
タグが消えても即座に全画面再探索しません。紙の外観を96×64pxで保持し、ロスト中は周囲を広げたROIのテンプレート照合で復帰候補を確認します。候補が出た時にタグを再認識し、部分遮蔽への対処として15回に1回もROI内で再認識します。オプティカルフローを毎フレーム実行する処理はありません。背景は160pxの縮小画像を正常時1秒間隔・ロスト中100ms間隔で取得し、小さな背景パッチの照合で移動を監視します。背景テンプレートは紙の位置を確定した時だけ更新します。見失った場合は登録済みの別の紙も順に確認します。背景移動を検出しない間は最後に測った位置を保持し、保持中と経過時間を明示します。背景移動を検出した後は旧位置を現在位置として使いません。背景が無地・全面遮蔽の場合は動いたか断定できません。保持値は新しい測定値ではありません。ロストが30秒続いた時と、その後30秒ごとに全画面を再探索します。「紙を探し直す」では直ちに再探索します。登録済みの紙どうしの配置を照合し、基準座標を保って再捕捉します。同じIDの複数紙を取り違える候補は、他の登録紙との一致を要求します。初回探索と30秒ごとの全画面探索には通常追跡より時間がかかります。
## 操作
1. 印刷した紙に合わせて模様を選びます。既定は40 mm角15個。60 mm角8個（横4個×上下2段）と24 mm角45個も選べます。A4横で印刷します。Chromeは従来どおり直接印刷、Safariは実寸A4のPDFを開いて共有→プリントを使います。
2. 紙に印刷された100 mm線を測って実測値を入力します。旧パターンを82%で印刷した場合は82 mmを入力します。紙の寸法と印刷模様の寸法は別です。
3. 壁・平面モードでは紙を平らに固定します。紙の中心が原点、紙の右がX、上がY、印刷面から手前がZです。実寸位置の精度にはレンズの校正も必要です。
4. 各カメラに同じ1枚の紙を映して画像・動画を読み込み、「位置を保存」を押します。筒モードでは左右に並ぶ共通タグを2個以上映し、フレーム選択後「カメラ1・2の配置を求める」を使います。
5. 1本の動画から形を読み取る場合は、固定した紙を左右から撮影した動画をカメラ1に入れ、「動画から筒の形を読み取る」を押します。共通タグと視点差を持つフレームを選び、復元後は各フレームの位置推定へ進みます。
6. 3D表示にはカメラと復元したタグの角・辺を表示します。映像の緑枠は検出、桃色は再投影です。配置を保存するとK/D、位置・向き、変換行列、観測点、復元点をJSONへ出力します。
## 動画の後処理
「全フレームを解析」はMOV/MP4のサンプル表をMP4Box.js 2.5.0で読み、WebCodecs VideoDecoderの出力を順に処理します。ファイルのフレーム時刻を使い、60 fpsなどの固定刻みを仮定しません。デコード待ちを制限し、解析が終わるまで先へ進む量を抑えます。完了時は期待フレーム数と処理数の一致を確認します。未検出も1フレーム分の結果として記録します。動画プレビューの再生は最新フレーム表示であり、全フレーム後処理には解析ボタンを使います。
解析中は検出枠、進捗、動画内時刻、色別タイムラインを更新します。停止しても完了済み結果を保存できます。JSONのposeはmm単位、動画時刻は秒、timestampUsは元の表示時刻（マイクロ秒）です。配置の書き出しは従来どおりm単位です。
認識はCPUのOpenCV/WASMです。WebGPUを使っていません。300 msの認識を16.7 msに高速化した変更ではなく、処理に時間がかかってもフレームを飛ばさない経路の追加です。HEVC等のWebCodecs対応はブラウザ環境に依存します。通常の非フラグメントMOV/MP4を対象とし、音声は解析しません。

## レンズ
既定の平面モードはA4からの画角推定です。4タグ以上を使って平面のホモグラフィから焦点距離を求め、1タグずつ除外した再計算と再投影誤差で候補を確認します。推定成功後はその値を保持し、通常追跡で画角を再計算しません。画像中心を主点、画素の縦横比1、歪み0とする近似で、レンズ校正とは区別します。正面に近い紙・小さい紙・不安定な候補では位置を確定せず、最大1秒に1回推定を試します。未推定時の65°による位置出力は行いません。「A4から画角を推定」を外した時だけ手入力に切り替わります。
歪みと主点も求める場合は、巻く前の平らな紙を距離・位置・傾きを変えて6〜20枚撮り「レンズを調整」を実行するか、保存済みのレンズ設定を読み込んでください。動画や写真を撮る設定と同じレンズ・ズーム・クロップを使います。出力のintrinsicSourceはa4-estimated、fov、calibratedを区別します。A4推定値には仮定と候補のばらつきを保存します。
3Dプレビュー下部の標準スクロールバーは表示だけを左右へ移動します。推定座標、回転行列、保存結果には影響しません。「上から」「斜めから」で表示位置を中央へ戻します。
校正の参照: https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html
## 印刷
OpenCV正規DICT_APRILTAG_36h11を使用します。既定の40 mm・15個版はID 300〜314。60 mm・2段8個版は510〜517、従来の標準45個は0〜44、旧Safari用45個は200〜244、旧Safari用15個版は400〜414、旧1段4個版は500〜503、旧Safari用1段4個版は550〜553です。旧印刷もIDから配置・実寸を判別します。
Chromeの印刷経路は277×190 mmのSVG・四辺10 mm余白を維持しています。Safariの83%縮小・PNG印刷処理は廃止しました。SVGと同じ模様座標をベクターPDFに出力し、A4横297×210 mm・1ページ・60 mm角を維持します。PDFにはURL・日付・ページ番号を描画せず、PrintScaling Noneを指定します。プリンターの最終倍率は基準線を測って確認してください。基準線は100 mmです。
SafariでURL・日付などが入る印刷ヘッダ・フッタをサイトから強制禁止する標準APIは確認できません。ユーザーの後続指示に従いSafariではPDFを印刷する経路へ変更しました。PDFのA4寸法・1ページ・ベクター描画・フッタなしはPopplerによる解析とレンダリングで確認しました。iPad実機のAirPrint出力は未確認です。

## 幾何処理
AprilTag専用の輪郭検出を使用します。2視点の同じID・同じ角点を対応付け、レンズ歪みを補正し、正規化8点法・RANSAC・Essential行列分解・正の奥行き判定を経て3D点を三角測量します。実寸への尺度は印刷したタグの縦辺から求めます。断面の円形仮定は使用しません。少数点、1列だけ、同一画像、視点差不足、外れ値過多、再投影誤差過大、尺度不整合は棄却します。
動画の形状取得は検出した複数フレームの候補から上記条件を満たす組を探します。復元された点だけをPnPに渡し、その後のフレームでカメラ位置を求めます。まだ復元していないタグだけが見える場合は、新しい位置を求められません。全周の地図拡張や変形追従は未実装です。
原点は最初の基準フレームのカメラ位置、Xはそのカメラの右、Yは上、Zは後方です。床座標の校正ではありません。JSONの単位はm、行列は行優先、カメラ軸はOpenCV規約（右・下・前）。カメラ中心は-R^T tです。
紙の断面復元と継ぎ目の重なり量の直接計測は同じ処理ではありません。手入力とゼロ固定は画面の経路から除きましたが、紙端を検出して重なり量をmmで自動計測する機能は未実装です。見えない継ぎ目を既知として扱いません。
