# エピポーラ表面スキャンPoC
https://epipolar-surface-rescan.daisukedaisuke389137.chatgpt.site/
2台のRGB動画から、壁・床・一般の物体を含む空間の3D表面を復元するブラウザーアプリです。A4のAprilTagでカメラを校正し、エピポーラ線上のRGB照合、ステレオ深度と三角測量を接続します。物体が人間かどうかは判別しません。復元後に背景と同じ深度・背景より手前・判定保留へ分けて確認できます。
## 役立つ場面
深度カメラを使わずに、2つの映像からどの範囲を復元できるか確認できます。元映像上の左右対応点、3D点群、接続した面を比較し、欠測や誤った接続を見つけながら撮影条件を調整できます。点群と表面をPLY、校正と対応情報をJSONで保存できます。
## 撮影と準備
同じ対象と同じ実物のA4用紙が両カメラに写るように撮影します。カメラと背景は固定し、対象がいない背景フレームも用意します。「大きな模様・横4個×上下2段」をA4横・倍率100%で印刷し、100mmの基準線を実測して入力してください。タグは60mmです。同じ印刷物を複数置いた場合も、左右で同じ実物の紙を指定します。
動画はブラウザー内で処理し、サーバーへ送信しません。HTTPSまたはlocalhostでdistを配信してください。WebCodecsを利用できるブラウザーが必要です。
## 使い方
1. カメラ1・2に動画を選び、「音声から時刻差を確認」を実行します。符号は「カメラ2時刻＝カメラ1時刻＋時刻差」です。左右の動作が揃うことも確認してください。
2. 複数の紙が鮮明に見える時刻へ移動し、「タグと画角を確認」で紙番号を確認します。「同じ紙の組」の2:1はカメラ1の紙2とカメラ2の紙1です。
3. 「2台を同時校正」を実行します。異なる時刻や紙の組でも校正値を確認し、不安定な場合は撮影条件を調整します。「2台の校正を保存」で再利用できます。
4. 対象がいない背景時刻をカメラごとに入力し、「指定時刻を背景として学習」を実行します。動画・校正・処理幅を変更した場合は背景を学習し直してください。
5. 対象のいる時刻へ移動し、「表面をスキャン」を実行します。「照合設定・診断」の「深度の復元」で、実測対応のみ、最小二乗の追加照合、実測対応と表面推定を切り替えられます。初期設定の表面推定は検証中です。「対応点を元映像で確認」で左右を比較できます。橙色の推定深度は独立した実測対応ではありません。
6. 初期設定は「壁を含む全シーン → 後から分離」です。背景と同じ深度・背景より手前・判定保留を切り替えて確認できます。「背景・影を除く」は前景だけを比較するための選択肢です。
7. 面は初期表示ではオフです。「近傍点を接続」はDelaunay三角形分割、「格子の隣接点だけ」は画像格子の隣同士を使います。接続距離の上限は初期値0.2mです。大きくすると離れた部位をつなぐ場合があります。頂点は観測点ですが、面の内部は未観測の接続推定です。異なる背景分類の点をまたぐ面は接続しません。
8. 「点群PLYを保存」は全観測点と分類ラベル、「表面PLYを保存」は同じ点と三角形、「結果を保存」は校正・対応座標・分類・時刻・処理内訳を保存します。ラベルは0＝保留、1＝静止背景、2＝背景より手前です。
## 対応動画での設定例

## 処理と時間表示
AprilTag検出にはOpenCV公式実装を使います。通常は紙のROIを局所検出し、30秒ロストした場合は別Workerで全画面を探索します。「紙を探し直す」で直ちに再探索できます。局所処理の時間と全体探索の時間を区別して表示します。
表面スキャンでは校正から歪みを補正して画像を平行化し、同じ行の候補をWebGPU版StereoSGBMで照合します。RGB局所相関、左右往復整合性、正深度などで対応を評価します。最小二乗照合では、実画像の局所的な拡大・せん断とRGB各色の明るさを調整し、左右の画素値の残差を小さくします。採用した対応から隣接画素へ探索を広げます。この追加照合と、近隣点からの深度推定は別に記録します。
表面推定では、実測点からOpenCV RANSACと最小二乗で局所的な視差平面を求め、傾いた面に沿うRGB窓で近隣の候補を比較します。色による支持重み、実測深度とのずれ、左右間の面候補の検証を使います。元の観測点を保持したまま、追加深度を種別6として保存します。色が似た異なる面や遮蔽の扱いは検証中であり、面推定による点数の増加だけで精度向上とは判断できません。
全シーンではMOG2や背景RGBの類似を理由に点を先行削除しません。復元した視差を無人背景の左右両視点と比較し、同じ深度・手前・保留に分類します。背景の欠測には、背景実測点からOpenCV RANSACで推定した平面を支持点の囲む範囲だけで併用します。平面モデルは背景の推定であり、現在の点群へ頂点を足しません。露出補正を推定できない場合は未確定と表示します。
動画の実タイムスタンプからフレームを選び、同期残差を記録します。動く対象の別時刻の点群は積み重ねません。表面接続は照合後の点群に適用され、点の座標・採用条件を変更しません。
## 現在の制約
無地、反射、遮蔽、視点差、校正誤差によって欠測と誤対応が残ります。空間全体の連続した表面復元は検証中です。面の接続は欠測部分の正解を保証しません。両カメラから見えない裏面は観測できません。再投影誤差が小さいだけで対応の正しさを判断しないでください。
GPU実行時間と、映像取得・転送・OpenCV処理・表示を含む全体時間を別々に表示します。全スキャンはまだ実時間動作の目標を満たしていません。校正時刻や用紙の組によるカメラ間隔推定の変動も未解決です。測定条件と結果はVALIDATION-20261111.mdに記載しています。

OpenCV 4.13.0、Three.js 0.170.0、MP4Box.js、Delaunator 5.0.1、robust-predicates 3.0.2を使用します。ライセンスはdist内およびdist/vendor内に同梱しています。Delaunatorの変更は依存モジュールの参照先だけです。
